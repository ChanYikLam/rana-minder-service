# 数据库访问适配 · PostgreSQL 连接与 RLS 上下文开发指导

> 更新日期：2026-08-12
> 目录位置：src/adapters/db/
> 权威依据：[系统架构总览 v1.0](../../../docs/architecture/系统架构总览-v1.0.md)（§5.1 适配与执行层）、[ADR-005](../../../docs/architecture/ADR-005-数据隔离与选择性RLS.md)、[ADR-014](../../../docs/architecture/ADR-014-单数据库与统一应用业务Schema.md)；[部署运维与恢复手册](../../../docs/operations/部署运维与恢复手册-v1.0.md) §9（OPS-DB-001~005）

## 核心职责

PostgreSQL 访问的唯一适配边界：连接池管理与复用、事务管理辅助、RLS/连接上下文建立与清理、作用域一致性验证，以及迁移/维护/恢复/特权连接与普通流量的隔离。数据库是本地业务事实权威（§4.1）：权威库不可用时停止业务写入，不得返回假成功。

关键不变量：

- 每个受保护数据库操作从可信服务端身份和业务对象重建最小单目标或登记式集合只读上下文；在事务边界内建立并验证；成功、回滚、异常、超时、取消后清理；连接归还池前证明无跨请求残留；缺失、污染、格式错误或类型混用时失败关闭（运维手册 §9.1）。
- 集合只读上下文不能写入；客户端不能伪造或扩大集合；连接池复用、取消和错误路径必须进入负向验证（OPS-DB-003）。
- 普通应用和后台任务身份不得绕过 RLS；迁移、维护、恢复或特权连接与普通流量隔离（OPS-DB-004）；扩展安装与结构变更只由受控迁移身份执行（OPS-DB-005）。
- 单数据库统一应用业务 Schema，不按社团或领域模块拆库/拆 Schema（OPS-DB-001、ADR-014）。

## 关键组件

| 组件 | 类型 | 职责 |
|---|---|---|
| `DbConnectionManager` | 连接管理（实现） | 连接池生命周期、借出/归还、复用、健康检查与归还前残留证明；`database/` 文档仅索引 |
| `ConnectionContextBuilder` | 上下文辅助（实现） | 从可信身份与业务对象重建最小单目标或登记式集合只读上下文并验证；实现 `shared/RlsContextHelper` 接口 |
| `ContextGuard` | 事务辅助（实现） | 事务边界内建立上下文、跟踪生命周期、在全部结束路径清理并证明无残留；实现 `shared/RlsContextHelper` 接口 |
| `PostgresTransactionContext` | 事务辅助（实现） | 显式本地事务收口：成功、回滚、异常、超时、取消路径的清理辅助；实现 `shared/TransactionContext` 接口 |
| `PrivilegedConnectionProvider` | 特权隔离 | 迁移、维护、恢复专用连接与普通流量的隔离边界（OPS-DB-004） |

## 核心接口

DbAdapter 核心接口：
- beginTransaction(): Promise<TransactionContext>
- commit(tx: TransactionContext): Promise<void>
- rollback(tx: TransactionContext): Promise<void>
- setRlsContext(tx: TransactionContext, scope: RlsScope): Promise<void>
- clearRlsContext(tx: TransactionContext): Promise<void>
- query<T>(tx: TransactionContext, sql: string, params: unknown[]): Promise<T[]>

## 使用与准入规则

- 业务模块经本适配访问数据库；每个受保护操作必须携带可信服务端身份与业务对象作用域，由本目录建立并验证上下文。
- 上下文必须与入口能力一致（单目标只读/集合只读/读写），并在事务边界内建立、验证与清理；归还池前必须证明无残留。
- 集合只读上下文禁止写入；客户端提交的社团标识、角色标签、缓存值或旧链接不得成为上下文来源（ADR-005 §2.7）。
- 禁止：普通应用与后台任务身份绕过 RLS；迁移/维护/恢复/特权连接接入普通流量或临时切换给普通请求；无上下文或上下文缺失时访问受保护数据；未经负向验证宣称连接复用安全。

## 核心逻辑摘要

- **上下文生命周期（运维手册 §9.1）**：重建最小上下文 → 事务边界内建立并验证 → 按入口类型使用读写能力 → 成功/回滚/异常/超时/取消全部清理 → 归还前证明无残留 → 缺失或污染失败关闭。
- **RLS 纵深防御（ADR-005）**：应用层逐请求授权是业务判定，RLS 只作数据库兜底；联合协作域独立建模与授权，不得放宽普通作用域过滤获得跨社团访问。
- **身份与连接隔离（OPS-DB-004/005）**：普通/后台身份无 RLS 绕过与扩展管理权限；迁移、维护、恢复与特权连接必须隔离，产品超级管理员不映射为数据库高权限（OPS-ID-001）。
- **统一 Schema（ADR-014）**：单数据库统一应用业务 Schema，模块所有权靠命名、访问规则与测试保证；八类事务边界保持本地原子性，外部依赖不纳入本地原子提交。

## 典型调用链

HTTP 命令：`AuthMiddleware` 完成认证与作用域解析 → 应用命令组装授权上下文 → `DbConnectionManager` 借出连接 → `ContextGuard` 在事务边界内建立并验证最小上下文 → 领域数据读写 → 成功/回滚/异常/超时/取消均清理上下文 → 归还前证明无跨请求残留 → 归还池。后台任务同链，上下文来源为冻结任务的最小作用域与每次领取后的当前复核结果。
