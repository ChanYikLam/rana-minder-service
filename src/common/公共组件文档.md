# common · 公共组件与错误脱敏

> 更新日期：2026-08-12
> 目录位置：src/common/
> 权威依据：系统架构总览 §5.1、ADR-013 §2.6、接口契约 §8、SRS-状态机转换明细（29 状态机/306 转换）、OPS-CFG-005

## 核心职责

平台策略层的横向支撑底座：集中维护全局共享常量、枚举、错误定义与通用工具，保证错误分类、脱敏语义与状态机常量在整个后端只有一份实现、一个出口，归属架构总览 §5.1 平台策略层。

- **错误与脱敏语义**：稳定分类（IFC-ERR-001~016）＋安全追踪编号＋最小脱敏上下文；错误对象与运行日志绝不携带报名正文、内部评语、附件内容、完整联系方式、令牌、密钥、数据库结构、内部路径或其他社团对象（接口契约 §8、OPS-CFG-005）。
- **枚举与状态机常量**：只作权威规格的"引用"，不重新定义规则；与 SRS 状态机转换明细（29 个状态机、306 条转换）逐条一致，出现差异即缺陷（唯一责任模块见总览 §5.3）。
- **类型与结构校验辅助**：HTTP 输入、配置文件、Casdoor 回读与事件、后台任务载荷、文件元数据、数据库 JSONB 等跨信任边界输入，必须在使用前执行运行时结构、范围与业务前置校验（ADR-013 §2.6）。

关键不变量：

- common 内一切代码无状态、无副作用、无秘密；工具函数必须是纯函数，不持有连接、客户端或日志实例。
- 禁止承载任何领域业务逻辑——状态转换、拒绝原因、授权结论、外部结果解释归各模块 domain，不得下沉到 common。
- 禁止从 common 反向依赖任何模块或适配器；依赖方向只出不进，不允许出现模块名。

## 关键组件

| 组件                    | 类型     | 职责                                                                      |
| ----------------------- | -------- | ------------------------------------------------------------------------- |
| `ErrorCatalog`          | 错误定义 | 维护 IFC-ERR-001~016 稳定分类、对外语义与业务副作用约束                   |
| `ErrorFormatter`        | 错误工具 | 由异常构造"分类＋安全追踪编号＋必要脱敏上下文"的错误对象，统一脱敏出口    |
| `RedactionGuard`        | 校验工具 | 出站与落盘前拒绝或移除疑似秘密与业务正文，不先写原文再清理（OPS-CFG-005） |
| `StateMachineConstants` | 常量     | 从权威状态机明细同步的状态名、转换名、作用域与收口分类常量，禁止二次定义  |
| `AppEnums`              | 枚举     | 全局共享且与权威规格一致的枚举（作用域类型、事务类别、结果类别等）        |
| `RuntimeValidators`     | 校验辅助 | 跨信任边界输入的运行时结构/范围/前置条件校验原语（ADR-013 §2.6）          |

## 使用与准入规则

- **使用**：所有模块、入口与适配器按需依赖 common 的常量、校验器与错误构造；错误对象经统一出口产生，禁止各模块自造错误分类或自行拼装脱敏文本。
- **可以放进来**：与具体模块无关的全局常量、权威枚举引用、纯函数工具、错误分类与脱敏规则、运行时校验原语。
- **禁止放进来**：领域状态机规则与拒绝原因、业务正文或秘密的处理逻辑、数据库/HTTP/日志/SDK 依赖、任何模块特有的状态或常量（属于对应模块 domain）。
- **校验边界**：实体级业务校验（如按表单版本的字段校验）归各模块 domain 或 shared，不放入 common；common 仅提供 `RuntimeValidators` 校验原语（类型、范围、格式、结构等通用校验）。
- 错误对象只允许包含接口契约 §8 允许的分类与最小脱敏上下文：IFC-ERR-004 不得披露越界对象详情、IFC-ERR-010 跨社团只返回不可用与冲突区间、IFC-ERR-015 不向无权调用者区分存在性、IFC-ERR-016 可返回安全追踪编号。

## 核心逻辑摘要

- **错误语义**：每个错误保留稳定分类与唯一安全追踪编号；关键失败可审计（IFC-ERR-003）；对外只暴露分类与允许上下文，不猜测、不补造、不透明化内部细节。
- **脱敏语义**：字段允许清单式处理，疑似秘密按更严格级别处理（GOV-001、GOV-009）；拒绝发生在落盘/出站之前，不能先写原文再清理。
- **枚举与状态机常量**：新增或修改状态/转换必须先改权威规格（状态机转换明细、接口契约），再同步本目录常量；常量变化不得反向影响状态机行为。
- **校验辅助**：只提供原语与组合规则，不绑定具体对象；调用时机在使用点（入口/用例/适配器）业务判定之前。
- **生命周期**：静态只读、无初始化与清理，不参与事务、审计与连接池管理。

## 典型调用链

HTTP 请求进入 → 入口校验输入（调用 `RuntimeValidators`）→ 应用命令用例执行领域校验与本地提交 → 任一失败抛出分类错误 → `ErrorFormatter` 构造脱敏错误对象（分类＋安全追踪编号＋允许上下文）→ 按 IFC-ERR 语义返回；脱敏摘要同时进入 shared 审计写入器的提交边界，运行日志由 ops 按字段允许清单落盘。
