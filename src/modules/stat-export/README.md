# 领域模块 · 统计与导出

> 更新日期：2026-08-12
> 状态机：`SRS-SM-EXP-001`（导出任务，10 条转换；IFC-SM-029）

## 核心职责

权限内统计（同步只读查询）与异步导出（任务与产物生命周期）。统计从正式业务记录计算、任何人不可直接修改（STAT-003）；导出内容为申请时快照，生成后按快照执行但不授予访问，每次下载实时重新鉴权（EXP-003）；正式删除命中导出内容时使未过期导出失效，与 audit 模块删除清单一致（EXP-003、AUD-009）。统计与导出均不得反向改变源业务事实（ADR-002 §2.1）。

## 关键组件

| 组件 | 类型 | 职责 |
|---|---|---|
| `StatisticsController`、`ExportController` | Controller（interfaces） | 统计查询、导出申请/重试/提前删除/下载/状态入口与授权上下文 |
| `ClubStatisticsQuery`、`RecruitmentFunnelQuery`、`JointActivityStatisticsQuery` | 查询用例（application/queries） | 同步只读统计：口径计算、普通社团隔离、联合参与方边界、下钻权限 |
| `ExportApplyCommand`、`ExportRetryCommand`、`ExportDeleteCommand` | 应用命令（application/commands） | 推进 `SRS-SM-EXP-001`；申请幂等、快照冻结、租约/版本竞争 |
| `StatisticsSpecification`、`ExportTaskAggregate`、`ExportSnapshot` | 领域模型（domain/models） | 指标口径与失效传播规则；任务状态、范围/字段/附件快照、失权/过期判定 |
| `ExportFileWriter`、`ShortLivedUrlProvider`、`ExportDisposal` | 基础设施适配（infrastructure） | 对象存储写入（水印/公式转义）、短期下载地址、失效清理与删除传播 |

## 对外接口

- HTTP 路由前缀：待传输适配评审（社团侧统计与导出、平台侧统计与导出两组前缀）；路径以接口契约为准，不得临时编造。
- 外部适配：PostgreSQL（任务、快照与统计回源读取）；对象存储（导出文件字节、元数据与安全清理）；job 模块（导出生成任务、有效期截止任务、失权事件处理）。
- 关键外部调用：生成完成后站内通知，不通过邮件附件交付；下载每次实时鉴权并审计（IFC-QRY-007）。

## 核心逻辑摘要

- 状态机链路：`新建（NEW） -> 待生成（PENDING_GENERATION） -> 生成中（GENERATING） -> 可下载（DOWNLOADABLE）/ 失败（FAILED）`；`失败 -> 待生成/生成中`（重试沿用原快照，范围变化需新申请）；`待生成/生成中/可下载 -> 已失权（REVOKED）/ 已过期（EXPIRED）`；`待生成/失败/可下载 -> 已提前删除（PRE_DELETED）`；任一非删除终态命中正式删除清单 -> 已提前删除（EXP-003）。
- 事务边界：导出申请=第 1 类（任务＋快照＋审计同事务，IFC-TX-001）；生成阶段=外部效果命令（IFC-CMD-002，先持久化意图、未可信收口前返回处理中）；下载为查询（每次实时重验）；失权/过期=第 8 类派生失效（IFC-TX-008）。
- 幂等/租约/回读：申请幂等（同一请求不重复建任务、固定快照）；生成单任务租约（重复启动幂等）；生成成功按任务版本/文件哈希幂等，不重复文件与通知；下载幂等不等于免审计（每次下载留痕）。
- 个人副本与特权导出：普通成员/申请人下载本人报名表、附件、邀请与公开结果属个人副本下载，仍受归档访问规则约束；超管全局导出须填写用途并产生特权审计；被紧急停用的参与社团不能新建或下载相关导出，已有未过期链接立即失效。
- 拒绝条件：越权字段/记录（IFC-ERR-003 当前无权 / IFC-ERR-004 作用域不匹配）、面试官批量导出（IFC-ERR-003 当前无权）、社团停用或联合授权失效（IFC-ERR-006 业务前置条件失败）、安全开关关闭（IFC-ERR-011 安全限制；GOV-004）、超管全局导出缺用途/重认证（IFC-ERR-002 重新认证不足 / IFC-ERR-005 输入无效）、文件过期（IFC-ERR-007 状态冲突）、非申请人删除（IFC-ERR-003 当前无权）--拒绝且保持或转入失权/过期/删除。
- 失效传播：纠错、成员退出/移除、Casdoor Group 同步与正式删除后统计自动更新；已依法删除的数据不再出现于当前或历史统计；普通社团严格隔离，联合参与方仅可查看该活动统计；下钻明细继续记录级权限检查（STAT-003）。
- 统计口径：普通招新与联合活动分别统计不混合；多部门成员分别计入各部门、社团总人数按学号去重；历史录取接受数与当前成员数分别计算，不因后续移除改写录取历史；不提供成员排行榜或人员优劣排名。
- 文件安全（后端实现要点）：XLSX 公式安全转义、水印或元数据（导出人/社团/生成时间/导出编号）、附件 ZIP 附带导出清单、手机号/邮箱默认不导出、秘密标识永不导出（EXP-002）。
- 模块边界：不提供任何业务数据导入；当前成员/部门/职位关系继续从 Casdoor Group 同步，不以导入建立第二套当前状态。

## 典型调用链

`ExportController 申请导出` -> 记录级/字段级/附件权限核验 -> 原子提交：导出任务＋范围/字段/附件快照＋申请审计（第 1 类）-> job 取得任务租约开始生成 -> 按快照读正式源、写对象存储（水印＋公式转义）-> 回读校验文件哈希/大小 -> 状态转`可下载`、站内通知、生成审计 -> 每次下载实时重验权限/安全开关/有效期 -> 生成短期地址并记录下载审计。
