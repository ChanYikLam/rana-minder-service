# 平台支撑 · 运维与可观测性

> 模块定位：平台支撑模块之一（ADR-002 §2.2，按 ADR-011 收窄）
> 职责：脱敏运行日志、追踪关联、内置只读状态摘要、备份/恢复最近结果展示
> 上游权威：[系统架构总览 v1.0](../../../docs/architecture/系统架构总览-v1.0.md)、[ADR-002](../../../docs/architecture/ADR-002-逻辑模块与状态机唯一责任基线.md)、[ADR-011](../../../docs/architecture/ADR-011-内置最小观测边界.md)、[SRS v1.0 §11.2](../../../docs/specification/SRS-v1.0.md)

## 事务边界对照（IFC-TX-001~008）

对照[接口契约 v1.0](../../../docs/specification/接口契约-v1.0.md)事务边界定义，标注本模块参与情况（✓=参与，--=不参与）。

| 边界         | 名称               | 本模块参与 |
| ------------ | ------------------ | ---------- |
| `IFC-TX-001` | 本地业务状态转换   | --         |
| `IFC-TX-002` | 直接权益与通知     | --         |
| `IFC-TX-003` | Casdoor 外部写入   | --         |
| `IFC-TX-004` | 文件上传/检查/绑定 | --         |
| `IFC-TX-005` | 通知渠道投递       | --         |
| `IFC-TX-006` | 受控批量           | --         |
| `IFC-TX-007` | 正式删除           | --         |
| `IFC-TX-008` | 派生刷新与重建     | --         |

注：本模块为只读支撑模块，不参与任何写事务边界：只读状态页与日志查询不允许调用任何写命令（不得触发、重试或代执行应用命令、外部写入或任务操作）。

## 1. 定位与责任

本模块提供首版**内置最小观测**能力（`PRD-OPT-055`、ADR-011）：

- **脱敏运行日志**：与长期业务审计分离的普通运行日志；
- **追踪关联**：请求、后台任务和外部调用通过唯一追踪编号建立关联；
- **内置只读状态页**：面向超级管理员，展示应用版本/启动状态、数据库连通性、任务积压与最近异常，以及 Casdoor 同步、邮件、文件检查、通知和备份的最近结果与更新时间；
- **备份/恢复最近结果**展示。

本模块不保存人员业务结论，不把运行日志当业务审计或权限来源。

## 2. 关键组件

| 组件                        | 类型                             | 职责                                                                                                                   |
| --------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `StatusPageController`      | Controller（interfaces）         | 超级管理员内置只读状态页端点（仅当前有效超管可访问）                                                                   |
| `StatusSummaryQueryService` | 查询用例（application/queries）  | 聚合各适配器最近结果、判定过期与未知；不查询业务数据                                                                   |
| `LogQueryUseCase`           | 查询用例（application/queries）  | 脱敏运行日志查询入口（按追踪编号关联）                                                                                 |
| `RedactionRules`            | 领域服务·规则（domain/services） | 脱敏分类规则、字段允许清单、敏感内容拦截（纯规则）                                                                     |
| `RetentionRules`            | 领域服务·规则（domain/services） | 日志保留期规则：普通日志 30 天在线 + 60 天压缩归档（ADR-011 §2.1 基线 30 天，SRS §11.2 细化归档）、网络安全日志 6 个月 |
| `TraceIdGenerator`          | 领域服务·规则（domain/services） | 唯一追踪编号生成规则；追踪编号与业务幂等键区分规则                                                                     |
| `LogWriterAdapter`          | 基础设施适配（infrastructure）   | 脱敏日志写入（结构化字段、字段允许清单过滤）                                                                           |
| `TraceContextAdapter`       | 基础设施适配（infrastructure）   | 追踪上下文传递：HTTP 请求->应用命令->外部调用/后台任务                                                                 |
| `StatusSummaryRepository`   | 基础设施适配（infrastructure）   | 状态摘要存储、备份恢复结果证据读取                                                                                     |

## 3. 权威与边界

| 本模块可以                                                                                       | 本模块禁止（首版明确不做）                                 |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| 记录脱敏运行日志（默认保留 90 天：30 天在线 + 60 天压缩归档；网络运行和安全事件日志至少 6 个月） | 机器健康监测（CPU/内存/磁盘）                              |
| 生成与关联唯一追踪编号                                                                           | 独立探测进程/应用宕机自动发现                              |
| 提供超级管理员内置只读状态页                                                                     | 系统外运维告警（邮件/Webhook 等投递）                      |
| 展示备份/恢复最近结果                                                                            | 指标/追踪导出接口、OpenTelemetry/Prometheus/Grafana 平台   |
| （只读消费技术运行证据）                                                                         | 从状态页或本模块入口调用任何写命令、触发任务重试或外部写入 |
| 应用可运行时在状态页与日志中提示严重异常                                                         | 把观测数据当作业务、权限或任务执行权威                     |

核心不变量（ADR-011）：

1. 状态页读取技术运行事实或可重建摘要，**不成为**业务状态、权限、通知事实、任务执行权威或备份完成证明。
2. 状态来源过期时必须显示"未知"，不得以最近一次成功伪装当前健康。
3. 观测信息不得自动改变录取、邀请、成员、部门、职位、评价、权限或其他业务结论。
4. 业务审计独立长期保留，运行日志不得替代业务审计；业务幂等键与追踪编号不得混同。

## 4. 运行形态

- 状态页端点和日志查询走 HTTP 入口（`StatusPageController`、`LogQueryUseCase`）。
- 追踪上下文适配（`TraceContextAdapter`）在 HTTP 和 worker 两个入口都生效，确保请求、后台任务和外部调用共享同一追踪编号。
- 日志写入（`LogWriterAdapter`）在 HTTP 与 worker 两个入口都运行，统一执行脱敏与字段允许清单过滤。

## 5. 分层落位

```
interfaces/     内置状态页只读端点（Controller，仅超级管理员）
application/    状态汇总查询用例（`StatusSummaryQueryService`）：聚合各适配器最近结果、判定过期与未知
domain/         脱敏规则、保留期规则、追踪编号生成规则（纯规则）
infrastructure/ 日志写入（脱敏）、追踪上下文传递、状态摘要存储、备份恢复结果读取
```

- **interfaces**：唯一面向 HTTP 的入口是超级管理员状态页端点；端点必须执行当前超级管理员校验。
- **application**：组装"最近结果 + 更新时间 + 过期判定"；不查询业务数据。
- **domain**：脱敏分类、日志保留期、追踪编号与幂等键区分规则。
- **infrastructure**：日志框架适配、状态持久化、备份/恢复证据读取（来自运维/备份系统）。

## 6. 开发必须遵守的规则

### 6.1 日志脱敏（AUD-013、AUD-014）

- 普通运行日志**不得记录**：报名正文、内部评语、附件内容、完整联系方式、令牌或密钥（含 Casdoor/邮件/存储凭据）。
- 不得记录敏感字段的完整值；错误详情、连接信息、路径、版本和秘密按最小披露原则处理。
- 默认保留 90 天（30 天在线 + 60 天压缩归档）；网络运行和安全事件日志至少保留 6 个月；业务审计独立长期保留。

### 6.2 追踪与关联

- 每次入口请求、后台任务和外部调用必须具有唯一追踪编号及可关联的派生关系。
- 追踪编号必须与业务幂等键区分：幂等键用于去重，追踪编号用于关联，二者不得混同。
- 日志中应能由追踪编号串起：HTTP 请求 → 应用命令 → 外部调用/后台任务。

### 6.3 内置状态页

- 仅当前有效超级管理员可访问（只读）。
- 只读状态页不允许调用任何写命令：状态页与日志查询仅消费技术运行事实，不得触发、重试或代执行任何应用命令、外部写入或任务操作（ADR-011）。
- 展示内容固定：应用版本与启动状态、数据库连通性、任务积压与最近异常、Casdoor 同步/邮件/文件检查/通知/备份的最近结果与更新时间。
- 过期状态显示"未知"；应用可运行时严重异常在页面和脱敏日志中提示。
- 状态页不得成为备份完成证明或任务执行权威。
- 不得从本 ADR 推导机器健康端点、指标导出端点或外部告警 Webhook。

### 6.4 禁止事项（防止隐性扩大）

- 不建设独立监测进程、系统外运维告警投递任务、指标导出。
- 不把 Docker/反向代理/部署平台自身能力冒充产品内置能力。
- 不为已取消的外部告警设计投递事实（影响数据层与任务层）。
- 自动安全限制按 GOV-006 独立规则执行，本模块不干预。

## 7. 与相邻模块协作

| 协作对象        | 关系                                                       |
| --------------- | ---------------------------------------------------------- |
| job 模块        | 读取任务积压、最近异常、各任务类型最近结果；不改变任务状态 |
| 各领域模块      | 只消费技术运行证据，不读取/写入业务数据                    |
| 数据库/存储适配 | 数据库连通性检查、备份恢复最近结果读取                     |
| 安全/权限       | 状态页授权来自组织与授权模块的当前权限判定                 |

## 8. 测试要求

- 日志脱敏断言：报错场景下无报名正文、评语、附件、完整联系方式、令牌、密钥；
- 90 天默认保留（30 在线 + 60 归档）与归档切换行为；
- 追踪编号关联完整性；追踪编号与幂等键互不混同；
- 状态页：主题齐全、过期显示"未知"、非超级管理员拒绝访问；
- 应用可运行时异常提示；完全不可用时无虚假外部告警承诺；
- 状态摘要不是任务或备份权威（只读、可重建）。
