## 核心职责

平台/社团默认值、活动配置快照、学年/届次、模板与安全开关的不可变版本发布与生效范围管理。关键不变量（ADR-002 §2.1）：已发布版本不可原地覆盖（CFG-005）；发布失败时旧版本完整有效、不得混合生效（SRS-FAIL-013）；活动发布冻结快照，后续默认值变化不影响已发布活动（CFG-005）；本模块不拥有使用配置的领域状态。

## 对外接口

- HTTP 路由命名空间（具体 URL 未冻结，由[接口实现规格 v1.0 §6](../../../docs/specification/接口实现规格-v1.0.md) 落地后冻结；以[接口清单-HTTP端点-v1.0](../../../docs/specification/接口清单-HTTP端点-v1.0.md) 为传输层事实基线）：平台默认值与权限模板发布/回滚、社团覆盖与活动配置快照、年学/届次管理、安全开关、字段映射发布。
- 外部适配：PostgreSQL（不可变版本＋当前指针＋发布记录同事务）；缓存（权限模板/安全开关发布后立即失效，CFG-008）；job 模块（可选：发布后派生刷新/对账触发）。
- 关键外部调用：发布权限模板、字段映射等高风险配置前展示影响对象并二次确认；影响学生权益或管理员权限时通知（CFG-005）。
- 查询要点：配置查看与影响预览走版本化服务端目录（IFC-QRY-002）；预览基于发布前固定版本，确认执行时不重新查询宽范围，防止预览与生效范围不一致。

## 核心逻辑摘要

- 版本语义：修改/回滚=基于旧版本创建新版本并发布，不删除中间历史；邮件密钥不能通过普通回滚恢复旧明文，只能重新填写或轮换（CFG-005）。
- 发布原子性：原子切换当前发布指针并使缓存失效；任一对象失败时所有对象继续使用旧版本，不得部分对象使用新版本（SRS-FAIL-013、IFC-GEN-007）；重试前重新预览影响并校验当前状态。版本冲突时拒绝（IFC-ERR-008 版本冲突）。
- 事务归属：影响学生权益或管理员权限的配置版本发布=第 2 类直接权益与通知（IFC-TX-002 边界 2）--新版本、发布记录、关键审计与通知事实同事务原子保存，通知事实保存失败则发布整体回滚（IFC-ERR-016 内部提交失败）；不产生权益通知的配置修改为第 1 类本地业务状态转换（IFC-TX-001）；发布后缓存失效为提交后派生刷新（IFC-TX-008）。
- 三级范围解析：平台默认值与允许范围 -> 社团覆盖（限于允许范围内）-> 活动配置快照；活动发布时冻结快照，之后模板回滚与默认值变化不影响已发布活动；已发布活动只能在业务状态允许时单独修改配置。
- 学年/届次：平台初始化时区与学年分界日，系统自动生成学年并切换当前学年；切换当前学年不自动创建届次、结束招新或改变成员关系；已被正式业务引用的历史学年不得因规则变化被自动重写。
- 展示资料：社团展示名称/Logo/简介等修改立即生效且无需审批，不进入完整发布流程，但仍保留修改历史与审计；修改不改变 Casdoor Group、成员关系或权限。
- 安全开关：紧急开关（如 GOV-004 类）立即生效并优先于活动快照；权限模板发布后立即统一作用于关联职位 Group 的全部当前成员，权限缓存立即失效，已登录用户下一次受保护请求按新版本鉴权（CFG-008）。
- 作用域与审计：所有配置修改显示作用域和生效时间，记录旧值、新值、修改人并审计；发布、失败、缓存失效与回滚均审计。
- 高风险发布：权限模板、字段映射发布要求最近 10 分钟重新认证、实时确认当前 Group、填写原因、影响预览与二次确认（GOV-007、CFG-008）；重认证不足时拒绝（IFC-ERR-002 重新认证不足）；映射不存在、类型不兼容或可能造成批量数据丢失时禁止发布（IFC-ERR-005 输入无效 / IFC-ERR-006 业务前置条件失败）。
- 新社团接入：启用前必须存在负责人职位 Group 且至少一名有效负责人；检查重复绑定、层级关系、负责人连续性与权限越界，任一步骤失败保持未启用，不产生部分生效的权限（IFC-ERR-006 业务前置条件失败 / IFC-ERR-003 当前无权）。
- 字段映射：学号/账号与姓名是必需映射，真实数据启用后不得随意删除（IFC-ERR-005 输入无效）；学院、年级、邮箱等仅能从固定同步白名单映射，动态表单字段不能映射到 Casdoor；映射只决定外部字段位置，不改变只读/可编辑/双向同步规则；新映射发布后执行一次受控对账。

## 典型调用链

`ConfigController 发布配置` -> 基于当前发布版本创建新版本 -> 影响预览与差异校验 -> 高风险配置先重认证（10 分钟 proof）＋二次确认 -> 原子提交：新版本＋发布记录＋旧值/新值/修改人审计＋（影响学生权益或管理员权限时）通知事实（第 2 类直接权益与通知，IFC-TX-002；通知事实保存失败则发布整体回滚）-> 提交后信号触发缓存立即失效（权限模板/安全开关，派生刷新 IFC-TX-008）-> 影响方通知渠道投递（第 5 类，IFC-TX-005）；任一失败则当前指针与缓存保持旧版本，重新预览后重试。
