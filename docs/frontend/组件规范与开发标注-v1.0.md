## 1. 文档定位

本文详述公共组件的状态变体，并提供前端开发所需的尺寸、样式、响应式、可访问性与资源接口标注方法。43 个页面低保真画板和 J-01 至 J-05 可点击旅程索引已正式落位于 `docs/frontend/assets/wireframes`；桌面高保真与独立移动视觉稿由需求方外部绘制。本文定义开发合同与候选设计令牌，不能冒充外部视觉成果或代码实现。

## 2. 基础组件状态变体

### 2.1 按钮 Button

| 变体 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| primary | 主操作 | bg #134E4A / text #FAFAF9；hover #0F3D3E | bg #2DD4BF / text #1C1917；hover #5EEAD4 |
| ghost | 次操作 | bg transparent / border #134E4A / text #134E4A | border #2DD4BF / text #2DD4BF |
| danger | 危险操作 | bg #DC2626 / text #FAFAF9 | bg #FCA5A5 / text #450A0A |
| danger-ghost | 危险次操作 | border #991B1B / text #991B1B | border #FCA5A5 / text #FCA5A5 |

状态：default、hover（primary 向深色化，深色向浅色化）、focus（至少 2px 可见焦点环）、disabled（bg-muted + text-disabled）、loading（旋转图标 + 文字保留，禁用重复提交）。禁用原因必须在按钮附近以可见帮助文本呈现，并通过 `aria-describedby` 或等效关系关联；tooltip 只能作为补充，不能成为键盘或读屏用户获取原因的唯一方式。

尺寸：sm（视觉高 32px，padding 0 12px，font 0.875rem）、md（高 40px，padding 0 16px）、lg（高 48px，padding 0 24px，font 1.125rem）。圆角 6px。触摸环境中的交互命中区域建议不小于 44×44px；视觉尺寸较小时通过外层命中区补足，不能造成相邻目标误触。

### 2.2 输入框 Input

状态：default（border #8F8984 / #5F716C，分别与浅/深 elevated 背景达到 3.45:1）、focus（border primary + 2px 描边）、error（border danger + 错误文字）、disabled（bg-muted + text-disabled）、readonly（bg-muted，如学号/姓名只读字段）。

尺寸：高 40px，padding 0 12px，圆角 4px。标签在上方，label 与控件关联（可访问性）。

### 2.3 状态徽章 StatusBadge

| 语义 | 浅色（背景/文字） | 深色（背景/文字） |
|---|---|---|
| 成功/已接受/开放 | #DCFCE7 / #166534（约 6.49:1） | #14532D / #4ADE80（约 5.23:1） |
| 危险/已拒绝/失败 | #FEE2E2 / #991B1B（约 6.80:1） | #7F1D1D / #FCA5A5（约 5.28:1） |
| 警告/待处理/即将截止 | #FEF3C7 / #92400E（约 6.37:1） | #78350F / #FBBF24（约 5.43:1） |
| 信息/进行中 | #CFFAFE / #155E75（约 6.49:1） | #155E63 / #67E8F9（约 5.15:1） |
| 中性/已完成/已关闭 | #E4E7E0 / #57534E | #232B28 / #A8A29E |
| 内部选定（强调） | #FEF3C7 / #92400E | #78350F / #FBBF24 |

规则：图标 + 文字 + 颜色三重表达（非纯颜色）；圆角 4px，padding 2px 8px，font 0.75rem。上述候选组合均按普通文字 4.5:1 校验，实际设计与实现仍须对透明度、叠加背景、hover、focus、disabled 和高对比模式复测。

### 2.4 卡片 Card

结构：bg-elevated + radius-md + shadow-sm（悬停 shadow-md）+ padding space-4。标题 h2 + 内容 body。状态：default、hover、selected（primary-subtle 背景 + primary 左边条 3px）、disabled。

### 2.5 表格 DataTable

结构：表头 bg-subtle + 行 bg-elevated + 行间距 1px border。状态：default、hover 行（bg-subtle）、selected 行（primary-subtle）、loading（骨架行）、empty（EmptyState 居中）。数字列优先使用表格数字特性并按语义对齐；候选等宽字体不能成为数据正确性的依赖。移动端改为保持同等操作能力的卡片或可展开行。

### 2.6 弹窗 Dialog / 抽屉 Drawer

Dialog：居中，最大宽度 480px，bg-elevated + radius-lg + shadow-lg + 遮罩 rgba(0,0,0,0.5)。头部 h2 + 关闭按钮，中部内容，底部操作栏（右对齐，主按钮 + 次按钮）。使用 `role="dialog"`、`aria-modal="true"`、可关联标题/说明；打开时将焦点移入，限制焦点在模态内，Esc 关闭，关闭后把焦点恢复到触发元素。高风险操作在已进入不可逆提交阶段时不得用 Esc 假装取消服务端执行。

Drawer：右侧滑出，宽度 360px（移动端全宽），用于筛选与详情。阴影 shadow-lg。

### 2.7 提示条 Toast

位置：顶部居中或右上。类型：success（success-subtle + check-circle）、error（danger-subtle + alert-triangle）、warning（warning-subtle + clock）、info（info-subtle + info）。成功提示可在至少 5 秒后自动消失并允许暂停/关闭；错误、警告和带操作提示默认不自动消失。普通状态使用 `role="status"`/礼貌播报，错误使用 `role="alert"` 或等效紧急播报；重试按钮必须可键盘到达且不得复用已失效对象版本。

### 2.8 确认流 HighRiskConfirm

结构：步骤指示（选择 -> 预览 -> 重新认证 -> 确认）+ ImpactPreview 面板 + 10 分钟重认证提示 + 目标冻结摘要 + 二次确认按钮。危险操作用 danger 主按钮。

### 2.9 同步状态指示器 SyncIndicator

| 状态 | 图标 | 文字 | 颜色 |
|---|---|---|---|
| 同步中 | loader（旋转） | 同步中 | info |
| 已同步 | check-circle | 已同步 | success |
| 同步失败 | alert-triangle | 同步失败 | danger |
| 第三值冲突 | git-compare | 待本人选择 | warning |

### 2.10 空状态 EmptyState

结构：线性插图（非 emoji，120x120）+ 标题 h3 + 说明 small + 引导按钮（可选）。类型：无数据（inbox）、无权限（lock）、已归档（archive）、搜索无结果（search-x）。

### 2.11 页面状态容器 PageStateBoundary

页面必须使用统一状态容器承接 `EV-*-N/L/E/F/A` 五类证据，名称仅表示职责，不锁定具体组件库：

| 状态 | 组件职责 | 焦点与播报 | 恢复约束 |
|---|---|---|---|
| N 正常 | 显示权威当前状态、允许操作和作用域 | 首次进入聚焦页面标题；局部刷新不抢焦点 | 操作能力来自服务端当前投影 |
| L 加载 | 骨架、局部进度或明确处理中 | `aria-busy` 或等效语义；避免重复播报 | 命令提交禁用重复触发，不把等待显示为成功 |
| E 空数据 | 原因、筛选条件和安全下一步 | 聚焦空态标题，不跳过筛选上下文 | 只在查询成功且有权时显示为空 |
| F 失败 | 安全错误、支持编号和可恢复动作 | 错误摘要紧急播报；重试后返回触发点 | 重试必须刷新版本/权限，不能复用过期许可 |
| A 无权限 | 登录、资料门、失权或安全返回 | 聚焦拒绝标题；不暴露隐藏对象内容 | 前端呈现不替代服务端逐请求授权 |

### 2.12 响应式操作区域 ResponsiveActionRegion

独立移动视觉稿不是当前交付物，但组件必须保留以下行为合同：

| 页面族 | 窄屏行为 | 不得丢失 |
|---|---|---|
| 列表 | 筛选进入抽屉，行转卡片或可展开行 | 当前筛选、状态原因、行级操作、分页/续载语义 |
| 表单 | 分栏改单列，错误摘要和步骤状态置顶 | 标签、帮助、校验、草稿/版本状态、主次操作 |
| 工作台 | 指标与待办纵向堆叠，当前作用域持续显示 | 异常优先级、更新时间、工作空间边界 |
| 高风险命令 | 影响预览、重新认证、确认和分项结果纵向排列 | 目标冻结、不可逆说明、部分失败和安全返回 |
| 详情/结果 | 摘要与权威状态置顶，分区按需折叠 | 对象状态、最小拒绝原因、支持编号和恢复动作 |

## 3. 开发标注规范

### 3.1 标注内容

每个组件或外部设计页面使用设计工具或等效交付格式标注：

| 标注项 | 说明 | 示例 |
|---|---|---|
| 尺寸 | 宽高、内边距、外边距 | 按钮 120x40，padding 0 16 |
| 颜色 | 令牌名 + 色值 | --primary #134E4A |
| 字体 | 候选字族 + 回退 + 字重 + 字号 + 行高 | 候选中文字体 600 1.375rem/1.3；附系统回退 |
| 间距 | 相邻元素间距令牌 | space-4 16px |
| 圆角 | radius 令牌 | radius-md 6px |
| 阴影 | shadow 令牌 | shadow-md |
| 断点行为 | 各断点布局差异 | xs 单列，lg 三栏 |

### 3.2 令牌到代码映射

候选设计令牌可映射为 CSS 自定义属性；实际命名和双主题是否采用仍待技术与视觉评审：

```css
:root {
  --bg-base: #F7F8F5;
  --primary: #134E4A;
  --accent: #F59E0B;
  --text-on-accent: #1C1917;
  /* 其余见设计稿第 2.2 节 */
}
[data-theme="dark"] {
  --bg-base: #0B0F0E;
  --primary: #2DD4BF;
  --accent: #FBBF24;
  --text-on-accent: #1C1917;
}
```

### 3.4 低保真到开发交接合同

| 交接项 | 必须内容 | 禁止推导 |
|---|---|---|
| 页面定位 | `P-*` 页面 ID、`V-*` 设计视图 ID、`PB-*` 画板 ID | 从画板标题新增页面或路由 |
| 状态定位 | `EV-*-N/L/E/F/A` 稳定证据 ID及对应状态语义 | 把五种页面状态改写为业务状态机 |
| 交互定位 | J-01 至 J-05 索引中的步骤、分支和安全返回 | 用可点击链接替代服务端授权或状态转换 |
| 响应式定位 | 页面族规则、折叠顺序、关键操作与状态保留要求 | 仅因窄屏隐藏关键能力或原因 |
| 外部视觉回挂 | 43 个 `P-*`/`PB-*` 的对应关系和版本 | 以外部视觉稿改变业务事实、字段权限或安全边界 |
| 开发验收 | 需求/状态机/接口/测试追踪和评审结论 | 从低保真像素反推未经确认的实现常量 |

## 4. 一致性约束

1. 视觉候选方案获批后，所有组件消费语义令牌，禁止在组件内散落硬编码色值、字号和间距。
2. 若双主题方案获批，主题变体必须成对定义；深色 subtle 使用经实测的深色变体。
3. 状态图标 + 文字 + 颜色三重表达，不依赖单一颜色。
4. 禁用状态必须以可见且可被辅助技术关联的方式说明业务原因，不能只灰显或只用 tooltip。
5. 图标统一使用 Lucide Vue 并配文字/可访问名称；装饰图标对辅助技术隐藏，状态不得仅由图标或颜色表达。
6. 墨青＋琥珀及避开蓝紫色系是待确认视觉提案，不得在评审前写成产品强制事实。
