# RanaMinder 多社团联合面试需求发现记录

> 状态：产品行为已内部冻结；本文保留历史访谈过程  
> 最后更新：2026-07-28  
> 权威需求编号：`JNT-001`—`JNT-029`

## 一、业务定义

联合面试是两个或以上平等社团建立的临时跨社团协作域。多方共同面对同一申请人、共享完整报名与评价材料，但各自独立作出通过、调剂和录取结论。

普通面试与联合面试是完全独立的路径：已开始的普通面试不能转为联合面试；联合面试结束后，各社团需要继续考察时只能另建普通面试。

## 二、参与社团生命周期

1. 任一社团负责人或人事管理员可以发起，超级管理员可以代发；不存在牵头社团。
2. 全部拟参与社团分别确认后，联合活动才成立并开放跨社团资料。
3. 首次公布前可以调整拟参与社团，名单变化后全部拟参与社团必须重新确认。
4. 首次公布时，参与社团名单永久锁定，此后不得新增或主动退出社团；暂停、延长或重新开放报名均不解锁。
5. 首次公布是公开预告和名单锁定事件；首次开放报名才是联合招新正式开始事件。两者可以同时发生，但分别留痕。
6. 首次公布前，拟参与社团可以撤回意向，但名单变化后剩余社团必须重新确认。
7. 首次公布后，任何参与社团均不得主动退出；无法继续参与时进入紧急停用，或由全体社团一致取消活动。
8. 紧急停用不改变参与身份；停用方立即失去读写权限，其历史评分、评语和结论继续保留，作者归属不变。

## 三、申请人告知与共享

1. 申请人提交时能看到首次公布时已经锁定的全部参与社团，并决定是否接受共享。
2. 拒绝共享即不参加联合活动，但可以参加原社团另行提供的普通面试。
3. 活动进行中不新增参与社团，申请人的共享对象不会在提交后扩大。
4. 申请人继续参加联合活动时不能只针对其中某个参与社团撤回共享；参与社团紧急停用只暂停其访问，不改变锁定名单。
5. 各参与社团有权角色可查看完整报名表、图片、附件、联系方式、跨社团评价、结论和修改历史。
6. 锁定名单之外的社团不能追溯查看资料或通过本活动发出邀请，只能另建普通或联合活动。

上述规则已经作为产品规则确认。超级管理员在部署中代表校方，系统不再建设外部治理审批；完整跨社团共享由统一说明、全局功能开关、当前角色鉴权和特权审计约束。

## 四、一次联合面试与排期

1. 同一申请人无论申请一个还是多个参与社团，都只参加一次联合面试。
2. 联合活动不为各社团设置不同轮次。
3. 管理员预设时间、方式和容量，申请人自选并可在有空位时换时。
4. 截止未选由管理员安排；请假、迟到或缺席可以重排；管理员可调整已选时间。
5. 所有时间及出勤变化必须通知申请人。

## 五、评价与独立结论

1. 参与面试官可实时看到其他社团评分、评语和结论。
2. 面试官看到他评后仍可修改自己的内容，不强制填写理由，但必须保留完整修改历史。
3. 评分和评语在活动结束前均可普通修改；结束后立即锁定，只保留事实纠错。
4. 各社团独立形成通过、调剂和录取结论，不能强制另一社团修改。
5. 后续普通面试的数据和结论不回写联合活动。
6. 对应邀请尚未被接受时，社团可以修改自己的结论；邀请一旦接受，该社团的录取结论立即锁定，不能再改为不录取，成员流程也不回写该结论。

## 六、邀请与成员生效

1. 已报名社团可发录取邀请；未报名社团只能发加入邀请。
2. 邀请必须有有效期，逾期未处理视为拒绝。
3. 仅仍为待处理且未被接受的邀请可以撤回；接受与撤回并发时只允许一个成功。拒绝后可重发；尚未接受时结论变化并重新发出邀请，需要重新计算有效期。
4. 申请人可同时接受多个社团邀请。
5. 接受时间作为成员业务生效时间，Casdoor 回读确认前不开放权限。
6. 邀请一旦接受便成为不可逆历史事实，申请人和社团均不能通过联合活动把它恢复为待处理、已撤回或不录取。
7. 接受后无论活动是否结束，申请人离开走成员退出，社团主动终止身份走成员移除，仅结束部门关系走部门关系移除；成员流程不改写原邀请和结论。
8. 某一社团通过成员流程改变关系时，不影响申请人在其他参与社团的邀请、结论或成员身份。

## 七、结束、归档与纠错

1. 正常结束要求全部邀请进入终态，并由全部参与社团在确认期限内一致确认。
2. 超级管理员可强制结束；未处理邀请立即失效并通知，已接受成员不受影响。
3. 完整材料、评价、结论、邀请和拒绝记录长期保留。
4. 结束后普通面试官失去访问；管理访问按当前有效角色计算。
5. 申请人查看自己的报名和邀请，不查看内部评价或纠错日志。
6. 结束后只允许事实纠错；原值、修正值、作者和处理历史不得覆盖。

## 八、新确认的运营边界

### 全体确认超时

1. 发起联合活动或在首次公布前调整拟参与社团时必须设置确认期限。
2. 期限内未全体确认，本轮关系自动失效，从未正式成立，也不开放新增资料权限。
3. 发起人可调整后重新发起，但所有社团必须重新确认，不能沿用旧确认。
4. 首次公布后不再存在参与名单变更确认。

### 参与社团紧急停用

1. 被停用社团立即失去联合资料访问和写入能力，其他社团继续活动。
2. 被停用社团的路径和邀请期限暂停，不能新增或接受其邀请。
3. 恢复后按停用时长顺延。
4. 长期无法恢复并妨碍全体结束确认时，由超级管理员强制结束。

### 后续确认结果

共享排期、面试官管理、活动取消、首次公布锁定新增与退出、首次开放报名正式开始，以及第一份邀请后禁止取消均已确认；本段仅保留需求发现过程，不再构成待确认项。

## 九、取消活动与全局服从调剂

### 取消活动

1. 任一社团可以独立发出本社团邀请，不需要其他社团同意。
2. 整个联合活动首次发布正式邀请之前，取消活动需要全部参与社团一致确认。
3. 首次邀请发布后不能取消，只能正常结束或由超级管理员强制结束。

### 全局服从调剂

1. 联合活动中的“同意资料共享”和“服从调剂”是两个不同选择。
2. 同意资料共享是加入联合面试的必要条件。
3. 服从调剂的范围不是原报名社团内部，而是联合活动的所有参与社团。
4. 不服从调剂时，未报名社团仍参与面试和共享，但不能发出加入邀请；已报名社团照常录取。
5. 服从调剂时，所有未报名参与社团均可独立发出加入邀请，申请人最终接受或拒绝。
6. 服从调剂不能挑选部分社团，范围以首次公布时锁定的参与社团为准。
7. 调剂同时覆盖各参与社团本次开放的全部部门，不单独选择可调剂部门。

## 十、共享排期与面试官管理

1. 所有参与社团的负责人和人事管理员均可创建、修改共享面试时间段并安排申请人。
2. 各社团只能指派或撤销本社团面试官，不能管理其他社团的面试官。
3. 排期变化必须保留审计并通知受影响申请人。
4. 不提供面试官利益冲突申报、自动关系识别或强制回避功能；各社团仍可撤销并重新指派本社团的联合面试官。

## 本模块内部冻结结论

联合面试的产品行为已经内部冻结，覆盖成立、公布、开放报名、参与名单锁定、公布前意向撤回、共享同意、全局服从调剂、一次联合面试、实时评价、独立结论、跨社团邀请、成员生效、接受后成员流程、取消、正常/强制结束、停用降级和结束后纠错。

`JNT-007`、`JNT-008`、`JNT-020`、`JNT-028` 涉及固定参与方完整跨社团材料共享、长期保留和特权访问，属于已接受的高风险规则。部署中的超级管理员代表校方，不再等待外部审批；真实数据使用仍必须通过实际 Casdoor、权限隔离、文件安全和通知能力的技术验证门。
