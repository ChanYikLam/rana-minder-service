# RanaMinder 前后端契约对齐 v1.0

> 文档状态：实现准备评审草案；前端文档组已确认需要接口适配层（[前端需求与交互规格](../frontend/前端需求与交互规格-v1.0.md) §接口适配），本文件定义前后端契约对齐的方式、切换清单与责任边界  
> 草案日期：2026-08-14  
> 权威来源：[接口清单-HTTP端点-v1.0](../specification/接口清单-HTTP端点-v1.0.md)、[接口实现规格](../specification/接口实现规格-v1.0.md)、[前端需求与交互规格](../frontend/前端需求与交互规格-v1.0.md)、[前端技术设计](../frontend/前端技术设计-v1.0.md)、[测试执行计划](测试执行计划-v1.0.md)  
> 用途：让前端 43 个页面与后端真实端点一一对应，定义 mock 切换真实后端的清单与门禁，明确错误码/信封的双端责任

## 1. 契约基线

`FEB-001`：

1. **语义基线**：接口契约 v1.0（传输中立，`IFC-*`）；
2. **端点基线**：接口清单-HTTP端点-v1.0（前端 mock 实际调用，269 端点）；
3. **规则基线**：接口实现规格（信封、17 类错误码、分页、幂等、版本、文件、认证）；
4. 三者冲突按权威顺序处理（接口契约 > 清单 > 规格），并回改下游。

## 2. 前端适配层职责（承接接口实现规格 §1.4）

`FEB-002`：前端接口适配器（`src/services/client.ts` 等价层）负责：

1. 统一信封生成：`action/targetId/expectedVersion/idempotencyKey/input`（`idempotencyKey` 命令端点自动生成，表单提交显式提供）；
2. 统一响应解析：`{ code: 0, data }` 成功、`{ code: "IFC-ERR-xxx", message, supportId, fieldErrors }` 失败、`202` 任务式（`IFC-ERR-013/014`）轮询；
3. 错误分类渲染：按 17 类 `IFC-ERR-*` 映射页面提示（§4 表），`supportId` 展示于错误详情供反馈；
4. 认证状态机：会话建立（`GET /api/auth/session`）、失效跳登录、`reauth` 增强认证流程（`IFC-ERR-002` 触发）；
5. 分页游标：按 `{ items, nextCursor }` 驱动列表加载（后端启用真实游标后适配）。

## 3. 页面 ↔ 端点覆盖核对

`FEB-003`：前端 43 个页面（[前端需求与交互规格](../frontend/前端需求与交互规格-v1.0.md) 第 3 节页面清单）与端点基线的覆盖核对方法：

1. 每页面列出其依赖端点（查询＋命令），与接口清单章节对照；缺失端点 → 补清单并登记差异（接口实现规格 §13）；
2. 每个端点反向标注使用页面，形成双向矩阵；矩阵随实现维护（建议置于前端文档组或本文件附录）；
3. 已知对照关系示例：
   - 公开探索页 ↔ `GET /api/explore/clubs`、`GET /api/explore/activities`、`/api/explore/joint/:id`（清单 §6）；
   - 报名页 ↔ `/api/activity/recruitment/:activityId/apply`、`draft`、`withdraw`（§11.1）；
   - 管理工作台 ↔ `GET /api/org/:clubId/dashboard`、`context`（§5）；
   - 面试官页 ↔ `/api/me/interviews/*`、`/api/org/:clubId/recruitment/:activityId/interviews/*`（§8/§11.5）；
   - 超管页 ↔ `/api/admin/*`（§15）；
4. 页面行为与端点动作映射须保持"动作子资源只表达登记过的逻辑操作"（接口实现规格 §6.2 规则 4）。

## 4. 错误码双端责任表（17 类）

| `IFC-ERR-*` | HTTP | 前端处理 | 服务端责任 |
|---|---|---|---|
| 001 | 401 | 跳登录/会话失效提示 | 认证失效判定 |
| 002 | 401 | 触发 `reauth` 流程后重试 | proof 校验（`SEC-IMP-003`） |
| 003/004 | 403 | 提示无权限/作用域；不展示对象详情 | 授权判定与脱敏 |
| 005 | 422 | 按 `fieldErrors` 逐字段提示 | 结构校验明细 |
| 006 | 422 | 业务拒绝提示（含状态机原因） | 前置条件/状态机守卫 |
| 007 | 409 | 刷新后重试 | 状态冲突判定 |
| 008 | 409 | 用响应当前数据刷新表单后重试 | 版本校验＋当前值返回 |
| 009 | 409 | 提示重复提交 | 幂等摘要冲突 |
| 010 | 409 | 提示资源竞争/刷新 | 单胜者裁决 |
| 011 | 403 | 禁用/安全限制提示 | 会话拒绝 |
| 012 | 503 | 降级提示＋`Retry-After` 重试 | 依赖不可用 |
| 013/014 | 202 | 任务轮询 UI（导出/同步） | 任务收口 |
| 015 | 404 | 统一"不存在"提示 | 不可见伪装 |
| 016 | 500 | 通用错误＋`supportId` 反馈 | 事务回滚、脱敏 |
| 017 | 400 | 请求构造错误提示 | 信封解析失败 |

## 5. mock 切换真实后端清单（对接接口实现规格 §13）

`FEB-004`：切换前逐项确认（对应差异登记）：

| 项 | mock 现状 | 真实后端 | 前端动作 |
|---|---|---|---|
| `nextCursor` | 恒 `null` | 真实游标 | 适配器按游标驱动（已预留） |
| 文件检查 | 3 秒假检查 | 真实检查任务（`IFC-FIL`） | 轮询 `status` 直到可用 |
| 导出下载 | `/api/mock-files/*` | 真实下载授权（1h 短链） | 适配 `downloadUrl` 域变化 |
| 换届状态 | 单例不按 clubId | 按 clubId 隔离 | 无改动（契约一致） |
| 时间推进 | 读取时惰性推进 | 截止任务推进 | 无改动 |
| 社团配置 | 任意键透传 | ConfigSchema 校验 | 仅提交登记字段 |
| mock 专用端点 | `/api/mock/*`、`?_mock_user=` | **不实现** | 演示模式仅在开发期 |
| 权限校验 | 部分端点未校验 | 全量鉴权 | 无改动（以 403 为准） |

## 6. 切换门禁

`FEB-005`：

1. 后端首批端点可用（登录/会话/公开探索/报名/管理最小集）后，前端以**契约测试**（对真实端点）替代 mock 回归（接口实现规格 §14、测试执行计划 L3）；
2. 43 页面全部切换真实端点且冒烟路径通过（开发环境搭建指南 §6）；
3. `FE-GATE-002/003`（可复现安装、类型检查、生产构建）证据按实际结果回填（`GOV-CODE-WAIVER-001` `WAIVER-SCOPE-005`）；
4. mock 层保留为开发占位，但**契约以真实后端为准**；禁止用 mock 行为解释契约差异。
