## 1. 定位与使用规则

`TVER-001`：

1. 本清单把上游已确认的**强制技术验证要求**收敛为可勾选执行表；每项验证必须记录：执行日期、执行人、环境指纹（版本、拓扑、样本）、结果、证据落点；
2. 证据落点：结果回填对应 `TST-*`/`OPS-VER-*`/`CAS-*`/`DATA-*` 入口与测试规格，不另造编号冒充；
3. 任一项失败：记录失败证据与处置（回退/升级/豁免），修复后重新验证；**不得静默降级为"参考"**；
4. 全部项完成后形成首批验证结论，作为真实数据启用与生产发布门的前置证据之一（门本身由需求方/治理流程控制）；
5. 执行环境优先使用[开发环境搭建指南](开发环境搭建指南-v1.0.md)的靶场；学校真实 Casdoor 实例验证须按数据治理规则进行，禁止真实学生数据入开发环境。
